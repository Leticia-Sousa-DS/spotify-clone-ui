<h2 id="started">📌 Sobre </h2>

Este projeto é um clone da interface inicial do Spotify, desenvolvido com HTML, CSS e JavaScript puro (Vanilla JS).  
É uma versão sem frameworks, focada em entender os fundamentos do front-end e a construção de layouts modernos.

> Projeto desenvolvido durante a **Imersão Front-End da Alura**.


#Imersao-front-end-alura

---

<h2 id="techs">💻 Tecnologias Utilizadas</h2>

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome (para ícones)

---

📁 **Estrutura simples**, ideal para iniciantes explorarem como interfaces modernas são construídas do zero sem frameworks.
